# SLP data-correctness audit fix — 2026-09-12

This change set addresses the confirmed export audit findings:

- TV+/Mobikino EPG clock values ending in `Z` are interpreted as UTC and converted to `Asia/Almaty` before temporal status calculation.
- `is_live_broadcast` is separated from the dynamic on-air status (`LIVE`, `UPCOMING`, `FINISHED`).
- TVGuide EPG presence alone no longer proves a direct broadcast.
- Replay/review/preview/classic/archive programming is not promoted to direct LIVE.
- The Telegram schedule may still contain sports EPG candidates even when direct-broadcast evidence is absent.
- XLSX `live` and `finish-upcoming` modes are filtered before workbook creation.
- XLSX contains an explicit timezone column and a distinct direct-broadcast column.
- The export button produces two distinct workbooks using the same status reference timestamp.

Regression coverage includes the audit examples for Tottenham–Everton, Brazil–Chile, Noche UFC, Viju Snooker Cup, Wimbledon, Formula 1, WRC preview and WEC review.
