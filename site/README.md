# SLP project site

This directory contains a static backup of the informational website for SLP — Skoomaholic's Sports Live Parser.

Production site: [slp-live-parser.alexandr-petrossov.chatgpt.site](https://slp-live-parser.alexandr-petrossov.chatgpt.site)

## Files

- `index.html` — page structure and content;
- `styles.css` — responsive visual system;
- `script.js` — progressive reveal behavior.

The site has no build step or runtime dependencies. Open `index.html` locally to preview it.
