Спортивное расписание

События по Алматы (UTC+5). В архиве сохраняются все известные каналы, в экспорте выбирается один.

Календарь

Список справа фильтруется по выбранной дате. Зелёная точка означает, что есть сохранённые LIVE-события.

События и архив

Данные поступают только из подтверждённых источников. При отсутствии почтовых файлов частичный сбор требует подтверждения. Веб-сервис не запускает Telegram-бота.
